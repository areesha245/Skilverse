# Skillverse

AI-style, game-based learning platform (academic prototype). Students turn notes into stories (Story Realm), explain concepts (Teach-Back Arena) and practise interviews (Interview Escape Room), earning XP and badges.

**Live site:**https://github.com/areesha245/Skilverse.git

## How to run
1. Clone or download this repository.
2. Open the folder in VS Code and run **Live Server** on `index.html`
   (ES modules and JSON loading need a local server; opening the file directly may be blocked by the browser).
3. Or just open the live link above.

## Structure
- `css/style.css` styles (no inline CSS)
- `js/` modules: auth, storage, ui, aiManager, gamification, storyRealm, teachBack, interviewRoom, progress, admin
- `data/` JSON: questions, rubrics, badges

## Demo accounts
- Students and teachers: use the Sign up page.
